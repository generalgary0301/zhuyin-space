# 注音太空探險隊

幫助小一生分辨捲舌音與平舌音（ㄓ／ㄗ、ㄔ／ㄘ、ㄕ／ㄙ）的闖關遊戲。

**永久網址：** https://generalgary0301.github.io/zhuyin-space/

六顆單音行星各有練習題，另有三顆對比雙子星。最終測試會播放單字發音，孩子用注音鍵盤寫出讀音（例如「蜘蛛」寫成 ㄓ ㄓㄨ）。

之後若要新增測試字母或增加練習單字，只要更新同一個專案再推送，網址不會改變。

## ✍️ 筆順訓練基地

ㄅ 到 ㄦ 37 個注音的筆順動畫與手寫練習（描一描、虛線寫、自己寫），每一筆都會檢查順序、方向和筆形。
